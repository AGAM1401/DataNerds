# DataNerds BI 📊

> An open-source, web-based alternative to Power BI designed to explore, aggregate, and visualize data from Excel workbooks (`.xlsx`, `.xls`) and CSV files with lightning-fast in-memory analytics.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitHub stars](https://img.shields.io/github/stars/AGAM1401/DataNerds?style=social)](https://github.com/AGAM1401/DataNerds)

---

## ⚡ Features

- **Excel & CSV Ingestion:** Drag-and-drop support for multi-sheet `.xlsx`, `.xls`, and `.csv` files.
- **In-Memory Analytical Engine:** Powered by **DuckDB** ("SQLite for Analytics") to execute instant SQL queries and aggregations across millions of rows without a heavy database server.
- **Power-BI-Style Visual Builder:**
  - Dynamic X-Axis (Dimensions) and Y-Axis (Metrics) selection.
  - Aggregations: `SUM`, `AVG`, `COUNT`, `MIN`, `MAX`.
  - Chart Types: Column Bar, Row Bar, Line, Area, and Donut/Pie charts via **Apache ECharts**.
- **Transparent Query Engine:** Displays the live SQL query generated by the engine for complete visibility.
- **Top-Level KPI Cards:** Automatically computes total rows, columns, and metric totals.
- **Full Data View:** Tabular inspection with auto-inferred column types (`number`, `string`, `date`, `boolean`).

## 🚀 Quickstart Guide

### 1. Start the Backend (FastAPI + DuckDB)

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run.py
```
> The API will start on **`http://localhost:8000`** (Swagger docs available at `http://localhost:8000/docs`).

### 2. Start the Frontend (React + Vite)

```bash
cd frontend
npm install
npm run dev
```
> Open your browser at **`http://localhost:5173`**.
